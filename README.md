
# Amoon Surprise Site ❤️

A mobile-first romantic one-page website built with Next.js.

## Run locally

```bash
npm install
npm run dev
```

Then open:

http://localhost:3000

## Music

The site is already wired for background music.

The uploaded track is connected here:

`public/music/02.We_Maloh.mp3`

The music starts after the visitor presses **نبدأ الرحلة ❤️**.

Use a track you own or are licensed to use.

## Change text

Most text and timeline content are in:

`app/page.tsx`

## Images

All uploaded images used by the website are inside:

`public/images/`

## Build

```bash
npm run build
npm start
```

## Deploy

The easiest deployment is Vercel:
1. Put this project in GitHub.
2. Import the repo into Vercel.
3. Deploy.
